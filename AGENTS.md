# AGENTS.md

Portfolio website for Lucas de Oliveira Amorim — Next.js, React, TypeScript and Tailwind, deployed on Vercel. Content is bilingual (PT/EN) and lives in `data/portfolio.ts` and `locales/`.

## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, with label strings equal to their names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
