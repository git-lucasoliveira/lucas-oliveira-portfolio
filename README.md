## 💡 Sobre o Projeto

Este é o repositório do meu website pessoal/portfólio.

> **Nota:** Como meu foco profissional é **Backend (Java/Spring)**, utilizei **Next.js 14 e IA** para construir esta interface. O objetivo foi garantir uma apresentação moderna, performática e com excelente UX para exibir meus projetos de arquitetura de software, sem desviar meu foco de estudos das tecnologias de servidor.

## 🛠️ Tech Stack (Frontend)

Embora meu forte seja o Backend, prezo pela qualidade visual e performance:

* **Next.js 14** (App Router)
* **TypeScript** (Tipagem estática)
* **Tailwind CSS** (Estilização)
* **Framer Motion** (Animações fluidas)

## 📊 Projetos em Destaque no Site

O site serve como vitrine para meus principais trabalhos de engenharia:

1.  **StarPeople (Enterprise):** Sistema de automação de onboarding implantado e em produção no Grupo Starcard.
2.  **RH System (Open Source):** API Restful focada em arquitetura limpa e segurança com Spring Security.

## 🚀 Como Rodar Localmente

Caso queira clonar este portfólio para estudo:

```
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev
```
Abra http://localhost:3000 no seu navegador.
